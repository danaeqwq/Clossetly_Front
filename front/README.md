# Clossetly

Aplicación de ropa :P

## React + Vite

Este proyecto utiliza React y Vite para desarrollar la aplicación Clossetly.

Vite proporciona un entorno de desarrollo con actualización en caliente (HMR) y reglas de ESLint para ayudar a mantener el código organizado.

### Tecnologías utilizadas

- React
- Vite
- JavaScript
- ESLint
